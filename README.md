#  Port Scanner

A Python-based network port scanner built for security reconnaissance.

##  What it does
- Takes target IP from user
- Scans a range of ports
- Detects open ports
- Saves results to a file
- Tell services name running on open ports

## How to use

```bash
python3 port_scanner.py
```

Enter target IP, start port, and end port when prompted.

## Example Output:
Port 22 -- OPEN
Port 80 -- OPEN
Port 443 -- OPEN
